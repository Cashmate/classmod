# classmod

Static site (index.html + weapon-data.js) presenting MORDHAU weapon and class data, comparing vanilla values against the CashClasses / CashWeapons mod values.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `github.com/Cashmate/classmod`, driven via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
